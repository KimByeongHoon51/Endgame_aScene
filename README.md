# Endgame_aScene

영화 「어벤져스: 엔드게임」 마지막 전투를 오마주한 팔라독 스타일 라인 디펜스 웹게임입니다. 영화 속 명장면 하나를 짧은 웹게임으로 구현하는 _aScene 시리즈의 작품입니다.

**플레이:** https://kimbyeonghoon51.github.io/Endgame_aScene/

**밸런스 테이블:** https://kimbyeonghoon51.github.io/Endgame_aScene/balance.html

## 기획 의도
「어벤져스: 둠스데이」 개봉에 맞춰 재개봉한 엔드게임을 극장에서 다시 봤습니다. 캡틴 아메리카의 "Avengers… Assemble"부터 아이언맨의 "I'm Iron Man"까지 이어지는 마지막 전투는 언제 봐도 소름 돋는 장면이었고, 이 장면을 직접 플레이하는 게임으로 만들어 보자는 생각에서 출발했습니다.

| 원작 장면 | 게임 규칙 |
|---|---|
| 캡틴의 "Avengers… Assemble" | 매 스테이지 시작 연출 — 날아온 묠니르를 잡고 외침 (실제 음성과 동기화) |
| 건틀릿을 지키며 버티는 어벤져스 | 건물 안에 건틀릿이 숨겨져 있다는 설정 → **건물이 함락되면 게임 오버** |
| 스냅에서 돌아온 히어로들의 합류 | 스테이지를 깰수록 새 어벤져스가 합류(해금) |
| 블랙 오더와 타노스 군단 | 스테이지마다 블랙 오더 보스, 마지막에 타노스 |
| 아이언맨의 스냅 | 스킬 「아이언맨 스냅」, 엔딩의 "I'M IRON MAN" → 타노스와 군단이 먼지로 |

## 개요
| 항목 | 내용 |
|---|---|
| 장르 | 라인 디펜스 (팔라독 스타일) — 식량으로 유닛을 뽑아 적 군함을 밀어낸다 |
| 플랫폼 | 웹 브라우저 (PC, 키보드·마우스) |
| 플레이 시간 | 스테이지 5개, 스테이지당 약 1분 20초~2분 |
| 그래픽 | 카툰풍 2.5등신 — 마블은 원작이 만화라 어색함이 덜하다고 판단 |
| 조작 | ← → 캡틴 이동 · 1~9 유닛 생산 · Q W E 스킬 |

## 핵심 규칙
- 매초 쌓이는 **식량**(팔라독 오마주)과 적을 잡아 얻는 식량으로 어벤져스를 생산합니다. 식량은 스테이지마다 초기화되고, 시작 식량 50으로 기본 유닛 3종을 바로 뽑으며 시작합니다.
- **캡틴 아메리카**는 플레이어가 유일하게 조작하는 캐릭터입니다. 가까운 적을 자동으로 공격하고, 쓰러지면 15초 뒤 부활합니다.
- **승리:** 타노스의 군함 파괴 (FINAL: 블랙 오더 4명 → 타노스 처치) · **패배:** 어벤져스 건물 체력 0
- **보스:** 등장할 때 충격파로 아군을 밀어내고 잡몹을 대거 데려옵니다. 군함은 보스를 쓰러뜨릴 때까지 방어막으로 피해가 75% 줄고, 보스를 잡으면 방어막이 꺼지며 식량 +100을 바로 받습니다.
- 유닛은 사거리 안에 적이 있으면 군함보다 적을 먼저 공격합니다.

## 캡틴 아메리카의 스킬
| 키 | 스킬 | 효과 |
|---|---|---|
| Q | 방패 던지기 (20초) | 적을 관통했다가 되돌아오며 다시 관통 |
| W | 묠니르 번개 (40초) | 앞쪽 적 전체 피해 + 기절 |
| E | 아이언맨 스냅 | 아이언맨이 날아와 스냅 → 모든 적 체력 50% 감소 (보스 10%). 적을 잡아야만 게이지가 차고 다음 스테이지로 이월, 전체에서 2~3번 쓰도록 설계 |

## 스테이지
| 스테이지 | 보스 | 새로 합류하는 어벤져스 |
|---|---|---|
| 1 무너진 기지 (절망) | 컬 옵시디언 — 체력 높고 공격 약한 첫 보스 | 호크아이 · 토르 · 아이언맨 |
| 2 치타우리 강하 | 프록시마 미드나잇 — 관통 창 던지기 | 워머신 · 헐크 |
| 3 지상군 총공세 | 코르버스 글레이브 — 관통 창 던지기 | 스파이더맨 · 닥터 스트레인지 |
| 4 블랙 오더 | 에보니 모 — 염력으로 아군을 날려버림 | 블랙팬서 · 스칼렛 위치 |
| FINAL 어벤져스, 어셈블 (희망) | 블랙 오더 4명 → 타노스 | — |

- 블랙 오더 4명 + 타노스 = 5스테이지. 보스 순서는 엔드게임에서 먼저 쓰러지는 컬부터, 마지막까지 살아남다 스냅으로 사라지는 에보니 모까지입니다.
- 스테이지가 오를 때마다 잡몹 수와 처치 식량이 10%씩 늘어납니다.

## 어벤져스 유닛
| 유닛 | 역할 | 식량 | 설계 |
|---|---|---|---|
| 호크아이 | 원거리 | 5 | 원거리 기준 유닛 — 건틀릿을 발견하는 캐릭터 |
| 토르 | 전사 | 10 | 전사 기준 유닛 — 마지막 전투의 첫 장면 |
| 아이언맨 | 원거리 | 20 | 하늘을 나는 딜러 — 마지막 전투의 첫 장면 |
| 워머신 | 전사 | 30 | 아이언맨과 차별점을 두려고 근거리 연사 전사로 |
| 헐크 | 전사 | 50 | 초반에 가장 비싸지만 가장 든든한 전사 (범위 공격) |
| 스파이더맨 | 원거리 | 30 | 둔화 — 적 이동 50%·공격 속도 40% 감소 |
| 닥터 스트레인지 | 원거리 | 50 | 넓은 범위 마법 |
| 블랙팬서 | 전사 | 30 | 가장 빠른 이동 속도로 빠르게 합류 |
| 스칼렛 위치 | 원거리 | 100 | 3명 동시 공격, 가장 긴 사거리 |

- 워머신·헐크는 건물에 갇혀 있다가 "어셈블" 이후 등장하므로 S2, 스냅에서 돌아온 네 명은 후반(S3·S4)에 합류합니다.
- 가격은 팔라독처럼 기본 유닛 5·10·20에서 시작해 해금될수록 비싸고 강해집니다.

## 밸런스 설계
**계산 → 시뮬레이션 → 플레이테스트** 순서로 맞췄습니다.

- **계산:** 전투력 = 체력 × DPS. 전사는 토르, 원거리는 호크아이를 기준으로, 비용이 k배인 전사는 전투력 k배(근접전은 머릿수에 비례), 원거리는 k²배(원거리전은 머릿수의 제곱에 비례 — 란체스터 법칙)를 적정선으로 봅니다.
- **시뮬레이션:** 자동 플레이 봇으로 전략 6가지(무작위 혼합·싼 유닛 물량·비싼 유닛 저축·전사만·원거리만·직접 고르기)를 스테이지마다 돌려 승률·클리어 시간·식량 수입과, 유닛별 실측(식량당 피해, 받아낸 피해, 공격당 맞힌 수)을 잽니다.
- **계산만으로는 부족했던 예:** 계산표에서 압도적이던 토르 물량 전략이 S4에서 10판 모두 졌습니다. 범위 공격, 생산 대기시간, 아군 40명 상한은 공식에 담기지 않아서, 범위·둔화·동시 공격 유닛의 공격력은 실측한 "공격당 맞힌 수"로 환산해 정했습니다.
- **현재 결과 (240판):** 일반 플레이(무작위 혼합) 기준 S1 81초, S2~S4 99~107초, FINAL 111초 · 7/8승. 스테이지마다 필요한 조합이 달라서, 전사만으로는 S4·FINAL을, 싼 유닛 물량으로는 S3부터 깨기 어렵습니다.

### 밸런스 테이블
모든 수치와 이름은 `balance.js` 한 파일에 있습니다. `balance.html`에서 고치고 **저장**하면 같은 브라우저의 게임에 바로 적용되고, **balance.js 내보내기**로 받은 파일을 교체하면 모두에게 적용됩니다. 같은 페이지에서 효율 지표, 전략 시뮬레이터, 유닛 실측 표를 볼 수 있습니다.

## 만든 방식
- HTML 파일 하나(Canvas 2D) + 밸런스 파일(`balance.js`), 외부 라이브러리·이미지 파일 없음. 캐릭터는 모두 코드로 그린 카툰풍
- 효과음은 Web Audio로 합성, 배경음은 유튜브 임베드
- 자동 플레이 봇과 전략 시뮬레이터로 스테이지마다 클리어와 시간을 확인한 뒤 GitHub Pages에 배포
- 진행 기록은 브라우저에 저장 (스테이지 선택 화면에서 초기화 가능)

비상업적 팬 오마주 프로젝트입니다.
