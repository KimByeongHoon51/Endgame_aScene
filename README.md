# Endgame_aScene

영화 「어벤져스: 엔드게임」 최종 전투를 오마주한 팔라독 스타일 라인 디펜스 웹게임 (카툰풍, 비상업 팬 게임).

**플레이:** https://kimbyeonghoon51.github.io/Endgame_aScene/
**밸런스 테이블:** https://kimbyeonghoon51.github.io/Endgame_aScene/balance.html

## 규칙
- 매초 쌓이는 식량과 적을 잡아 얻는 식량으로 어벤져스를 생산해, 몰려오는 타노스 군단을 막습니다.
- 캡틴 아메리카는 직접 움직이며 가까운 적을 자동으로 공격합니다. 쓰러지면 15초 뒤 부활합니다.
- **승리:** 타노스의 군함 파괴 (FINAL: 블랙 오더 4명 → 타노스 처치)
- **패배:** 무너진 어벤져스 건물의 체력이 0

## 조작
| 키 | 동작 |
|---|---|
| ← → / A D / 화면 버튼 | 캡틴 아메리카 이동 |
| 1 ~ 9 / 카드 클릭 | 유닛 생산 |
| Q | 방패 던지기 — 관통 후 되돌아옴 |
| W | 묠니르 번개 — 앞쪽 적 전체 피해 + 기절 |
| E | 인피니티 건틀릿 — 모든 적 체력 50% 감소 (보스 20%) |
| P / Esc | 일시정지 |
| M | 소리 켜기/끄기 |
| ? / H | 도움말 |

## 스테이지
| 스테이지 | 보스 | 새로 합류하는 어벤져스 |
|---|---|---|
| 1 무너진 기지 | 컬 옵시디언 | 호크아이 · 토르 · 아이언맨 |
| 2 치타우리 강하 | 프록시마 미드나잇 | 헐크 · 워머신 |
| 3 지상군 총공세 | 코르버스 글레이브 | 닥터 스트레인지 · 스파이더맨 |
| 4 블랙 오더 | 에보니 모 | 블랙팬서 · 스칼렛 위치 |
| FINAL 어벤져스, 어셈블 | 블랙 오더 4명 → 타노스 | — |

- 스테이지가 오를 때마다 잡몹 수와 처치 식량이 10%씩 늘어납니다.
- 인피니티 건틀릿 게이지는 적을 잡아야만 차고, 다음 스테이지로 이월됩니다 (전체에서 2~3번 쓰도록 설계).

## 밸런스 테이블
모든 수치(체력·공격력·비용·스테이지 구성 등)는 `balance.js`에 있습니다.
`balance.html`에서 고치고 **저장**하면 같은 브라우저의 게임에 바로 적용되고, **balance.js 내보내기**로 받은 파일을 교체하면 기본값이 됩니다.
